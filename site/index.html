dagr

A tiny, keyboard-first task list for Linux. One priority-ordered list, everything a single click away — and a built-in MCP server, so an AI assistant can do anything you can.

View on GitHub → Quick start

what it looks like

One window, GTK 4 and libadwaita, following your system light or dark style. Each row: check to complete, click the title to edit, the dot to re-prioritize, the bin to delete.

quick start

# Fedora — swap for your distro's GTK 4 + libadwaita dev packages
sudo dnf install rust cargo gtk4-devel libadwaita-devel

git clone https://github.com/alebles/dagr
cd dagr
cargo run --release

Tasks live in a single SQLite file at ~/.local/share/dagr/dagr.db. No account, no cloud, no telemetry. A Flatpak manifest is included for a sandboxed build.

scriptable by ai

The same binary is a Model Context Protocol server. Every action in the app is a tool, on the same database — so an assistant's changes appear in the open window within a second.

# run headless over stdio, or register it with Claude Code
dagr --mcp
claude mcp add --scope user dagr -- dagr --mcp

Or flip on the HTTP server in Preferences and connect over http://127.0.0.1:7331/mcp, bound to localhost while the window is open.

features

One click for everything

Complete, rename, re-prioritize, or delete — no menu, no confirmation dialog. Deletes offer Undo in a toast instead of asking first.

Priority-ordered

User-defined levels with names and colors. The order you set is the order the list sorts; drag the grip or use the arrows to change it.

Type to add

The entry is focused on launch. Type and press Enter; a leading !, !!, !!! bumps the new task's priority.

Adjustable

Turn priorities off entirely, choose the sort order, set the default priority for new tasks — all in Preferences.

AI-native

A built-in MCP server over stdio or local HTTP, sharing one database with the running window. Anything you can do, an assistant can too.

Native & private

GTK 4 + libadwaita, following the system theme and accent. A single local SQLite file. Runs on any Linux desktop, no GNOME shell required.
